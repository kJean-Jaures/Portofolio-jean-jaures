# Sources des logos

Les SVG VMware, VirtualBox, Microsoft Office, Zabbix, Adobe InDesign et OVH proviennent du catalogue [Dashboard Icons](https://github.com/homarr-labs/dashboard-icons/tree/main/svg). Les marques restent la propriété de leurs détenteurs respectifs.

Les autres logos produits proviennent du paquet Devicon déjà utilisé par le projet. Les notions sans logo produit utilisent un pictogramme distinct et une abréviation ; le repère Active Directory n’est pas présenté comme un logo officiel.
